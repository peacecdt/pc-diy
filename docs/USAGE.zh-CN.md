# 装机工坊 · 个人版 1.0

Windows 10 / 11，64 位。双击“装机工坊.exe”运行，无需另装 .NET、Python 或 Node。首次启动会解压内置运行时，可能稍慢。EXE 已内置硬件库，可单独运行；完整 ZIP 另附说明与数据许可。

## 已有功能

- 内置 26,254 个硬件型号，覆盖 CPU、主板、显卡、内存、存储、散热、电源、机箱。支持中文品牌关键词、型号检索、详细规格修订和 JSON 硬件导入。
- 4 套可修改示例：核显办公、1080p 游戏、2K 游戏、创作。示例预算只是目标，全部价格初始为空。
- 选择配件即时计算已录入总价，并评为“优秀／良／差”；缺件标“待完善”。逐项解释插槽、DDR、容量、空间、电源与散热问题。
- 配置自动保存，也可另存 JSON、重新打开、导出带购买搜索链接和评级说明的 HTML / 文本清单。HTML 可在浏览器打印。
- 联网硬件更新、失败保留旧库、商品查询、京东 / 淘宝搜索、手动价格与商品链接记录。

## 第一次使用

1. 左侧下拉框加载一套示例，或点击“新建空白配置”。修改用途和预算。
2. 点击左侧配件类别，在中间搜索；双击型号或点“加入配置”。支持“华硕 B850”“利民”等品牌词。
3. 右侧查看评级及改进原因。未知的关键参数会提示待核验；不要把“良”理解为已实测稳定。
4. 点“京东搜同款”或“淘宝搜同款”，在浏览器核对具体型号、规格套餐、卖家及库存。
5. 点“商品 / 报价”录入人民币金额，可附具体商品链接。左侧已选配件也可右键报价或移除。
6. 点“保存配置”另存 JSON；“导出清单”生成便于采购和打印的清单。

缺少的厂商参数可在“详细规格”中补齐后保存，评级立即更新。数值不带单位，多值以英文逗号分隔；未知内容留空。

## 自动联网的实际范围

**硬件库可直接更新，不需要密钥。** 来源为 [BuildCores OpenDB](https://github.com/buildcores/buildcores-open-db) 社区数据库。软件启动后及运行期间按设置间隔检查，默认 24 小时。新型号取决于上游社区何时收录，并非厂商发布当天必然出现。首次同步约 45 MB，需要能访问 GitHub；网络失败继续使用内置库或缓存。软件关闭后不驻留后台。

**京东、淘宝自动商品查询需要你自己的有效开放平台凭据和接口权限。**

- 京东：App Key、App Secret，使用 `jd.union.open.goods.query`。参阅[京东官方开放平台](https://jos.jd.com/jdunion)。
- 淘宝：App Key、App Secret、推广位 Adzone ID（`mm_xxx_xxx_数字` 的最后一段），使用 `taobao.tbk.dg.material.optional.upgrade`。参阅[淘宝官方 API 文档](https://developer.alibaba.com/docs/api.htm?apiId=64759)。
- 在“联网与数据”页填好后点击“保存联网设置”。凭据以 Windows DPAPI 加密保存在当前用户目录，不进入导出的配置文件。
- “更新本配置商品”会查询当前配置各配件的候选商品，每个平台每型号最多请求 30 条；也可在单个配件的“商品 / 报价”中查询。开启自动更新后，运行期间会按间隔查询当前配置。
- 候选是关键词结果，不能证明相同 SKU 或有货。必须打开商品页核对并勾选确认，才采用报价。自动刷新保留手动／已采用报价，避免把不同套餐的低价混进总价；新的候选仍可供重新核对采用。
- 未填写密钥时，京东／淘宝浏览器搜索入口和手动报价可直接使用。软件不代申请账号或接口权限，也没有附带别人的密钥。

**目前不能保证“所有配件均在京东淘宝有货”或“零配置全自动实时价格”。** 内置社区库包含旧型号和海外型号，不是已核验的国内在售商品库。未报价显示“未报价”，不虚构国内价格。国内能否购买以你打开的具体商品页和收货地区为准。

## 评级如何理解

- **差**：存在已知硬兼容问题，或多项明显短板。说明会指出具体配件、限制值和改进方向。
- **待完善**：缺少必需配件。
- **良**：未发现已知硬冲突，但参数、报价或搭配仍有待核验／改进之处。
- **优秀**：已提供关键参数的规则检查通过，规则评分较高。它不等于游戏跑分或整机实测通过。

电源估算采用 CPU、显卡标注功耗及其余部件预留，再留规划余量。若数据只有 CPU TDP，会明确提示并阻止直接认定最大功耗；厂商推荐电源、接口与瞬时负载要求优先。CPU / GPU 没有可信性能档位时，软件明确显示尚未判断性能平衡，不编造瓶颈百分比或帧率。未知规格不会被当作已兼容。

实际装机仍需核对主板 CPU 支持列表与 BIOS、内存 QVL、散热器扣具、显卡厚度和供电线、水冷安装位、走线空间等。

## 文件与备份

个人数据目录：`%LOCALAPPDATA%\PcWorkbench`。可在软件内点“打开数据文件夹”。包括自动保存配置、硬件缓存和加密联网设置；不要把整个目录随意发给他人。单独备份导出的 `.pcbuild.json` 即可保留配置与报价。更换 Windows 用户后，原 DPAPI 凭据需要重新填写。

软件不会自动下单、付款或发送配置给卖家。

## 验证与源码

已通过 55 项兼容性与评级测试；真实联网获取 26,254 条硬件及 HTTP 304 缓存复用测试；商品签名、响应解析、错误、取消及密钥脱敏测试；实际 EXE 启动、配件搜索添加、价格合计、配置读写、导出、DPAPI 加密往返与界面检查。

尚未取得真实授权凭据，因此**没有验证真实账号授权成功后的京东／淘宝报价**。网关可达和错误返回已经实测；正式使用仍取决于你的账号权限、配额和平台后续接口变更。

源码包内 `PcWorkbench` 使用 .NET 8 WPF。安装 .NET 8 SDK 后运行 `publish.ps1` 构建自包含 EXE。评级测试：`dotnet run --project PcWorkbench/tests/RatingEngine.Tests.csproj`；网络测试：`dotnet run --project network_probe/NetworkProbe.csproj`，加 `-- --live` 执行真实硬件联网测试。
